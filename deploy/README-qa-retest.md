## 导航与立即检查

- [ ] 桌面宽度大于 900 CSS 像素：展开与收起侧栏都能直接点击图标切换页面，收起状态保持。
- [ ] 窄屏宽度不大于 900 CSS 像素：初始关闭的导航不可被键盘聚焦或辅助工具读取；点击“打开导航”后可操作。
- [ ] 打开抽屉时焦点落在当前导航项，Tab / Shift+Tab 在抽屉内循环；Esc、关闭按钮、遮罩均能关闭，并把焦点返回“打开导航”。
- [ ] 选择导航项后抽屉关闭，焦点进入页面正文；再次打开仍能导航。反复调整桌面/窄屏宽度后没有遮罩残留或页面无法滚动的问题。
- [ ] 监视列表点击“立即检查”，网络请求返回 **202 JSON**：`status=queued`、对应 `watch_id`、非空 `request_id`，后者与响应头 `X-Request-ID` 一致；收到回执后才显示“已提交检查”。排队成功不代表扫描成功。
- [ ] 同一行快速双击只产生一次提交；检查完成后最后检查时间、状态和截图能更新，再次检查可用。
- [ ] 在测试环境模拟队列不可用，界面显示错误；模拟响应断线，界面显示“未收到检查提交确认”，没有成功提示和自动重试。先刷新检查时间，再决定是否手动重试。
- [ ] 若仍出现 `ERR_ABORTED`：保留网络日志，在当前页面等请求结束；记录请求时间、URL、`X-Request-ID`（有响应时）、检查审计与 worker 日志。检查是否伴随刷新、跳转、代理超时或浏览器自动化取消。提交日志前删去 Cookie、密钥和个人信息。

## 用户与权限边界

用分开的浏览器会话/账号测试，不用拥有多个管理员角色的同一个账号代替所有权限测试。这里描述的是已有权限设计的验收；离线界面测试不能替代后端与数据库验收。

- [ ] 超管可以创建本地用户、配置自定义权限集和角色；普通平台管理员可以管理普通用户，不能管理或授予超管。最后一个可用超管、最后一个本地超管不能被停用或移除。
- [ ] 新建/重设密码后的账号只能改密、查看自身、退出；直接请求业务接口也应返回 `403 password_change_required`。改密后旧会话失效，重新登录正常。
- [ ] 只读用户不能创建/修改监视、用户或授权；直接请求相应写接口返回 403，而不只是按钮隐藏。
- [ ] 仅有 `users:write` 的账号可进入用户管理，即使没有 `config:read`；不能进入角色/权限集编辑、主密钥、身份或业务设置。
- [ ] 仅有 `access:write` 的账号能维护授权定义；用户管理须另授 `users:write`。分配授权管理权限意味着能授予普通业务权限，应按职责分配。
- [ ] 自定义角色引用权限集后，用户实际权限为角色及直接权限集的并集。移除一项授权后确认没有其他角色仍授予同一权限。
- [ ] 修改/撤销权限后已有会话的 API 权限立即变化，前端在当前用户信息刷新后（通常不超过 15 秒）更新入口；停用、重设密码或注销全部会话后旧会话失效。
- [ ] 真实 Entra ID / OIDC 登录同步映射角色，保留 Web 手动追加的角色和权限集；停用用户不能通过 SSO 恢复；缺少有效映射角色时拒绝登录。
- [ ] 查看审计记录，确认包含操作人、目标、请求标识，且不包含密码或凭据原文。
