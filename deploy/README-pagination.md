# Web 列表分页

告警、监视列表、证书监控（含子域名详情）、账号保护（含候选详情）、文档搜索、报告、下架处置、仿冒活动、审计日志均支持页码、总条数与每页条数选择。默认每页 20 项，可选 10、20、50、100。切换搜索、筛选、监控对象或每页条数时回到第一页；删除导致当前页超出范围时自动回到最后一页。

连接器、抑制规则、模型供应商、活动成员、报告内容、证据、转载、泄露结果、规则试跑、配置版本历史及监视状态历史等已返回集合的列表使用前端分页。总览中的固定条数摘要和评分因素表保持简洁；可进入对应完整列表查看全部数据。

列表接口支持 `page`（从 1 开始）和 `limit`，响应增加按相同筛选条件统计的 `total`；活动接口沿用 `page` / `page_size`。证书子域名支持 `order=id|expiry_asc|expiry_desc`，账号候选支持 `order=id|score_asc|score_desc`，按完整结果集排序后再分页。

原 `cursor` / `next_cursor` 接口保留兼容，`page` 与 `cursor` 同时传入会返回 422，游标仅支持原 ID 排序。

本次没有数据库结构变更，需要同时更新 API 和前端。Docker 部署需重新构建并重建对应容器，不能只重启仍使用旧镜像的容器。证书入口权限说明见 [证书监控](README-certificates.md)。
