# 监视域名页面复查与截图

升级前运行 `uv run opti db-upgrade`，重新构建前端，并重启 API、worker、scheduler、境外采集节点和 browser 沙箱服务。确认 `http_probe`、`screenshot` 已启用，`OPTI_SANDBOX_URL` 能指向截图沙箱，采集节点能访问该服务，平台已配置对象存储。

「监视列表」的定时复查和「立即检查」现在会用隔离浏览器打开该域名首页，读取渲染后的标题、可见正文、最终地址及跳转链，保存截图与 HTML 快照。每次使用全新浏览器，只放行 GET/HEAD、公网地址；不登录、不提交表单，内网地址、下载、弹出窗口仍会被拦截。

列表展示页面类型、标题和截图缩略图。「页面内容与截图」显示最新正文摘要、命中的品牌词、最终访问地址、跳转路径、采集时间和截图；可选择历史复查记录查看先前内容。HTML 快照仍只作为纯文本附件下载，不在平台中执行。

停放 / 出售识别检查页面正文、标题中的域名出售信号，以及是否跳转到 Sedo、Afternic、Dan、HugeDomains 等域名交易平台。会区分网页可访问、停放 / 出售、非 HTML 响应、未读取到正文、访问验证页、跳转到其他站点、疑似冒用登录页和本次无法访问。页面可访问、包含品牌词或出现登录框都不是已确认仿冒，仍需人工结合内容及截图核查。

浏览器读取成功时采用浏览器看到的当前页面重新评分；截图服务失败时保留基础 HTTP 探测结果并提示尚未完成浏览器复查。网络故障继续保留上一次内部风险状态，界面明确显示本次无法访问，历史截图可从旧记录查看。没有解析或网页地址的域名不会生成截图。已有监视项在下一次定时复查生效，也可手动「立即检查」刷新。

查看页面信息沿用 `watchlist:read`，立即检查沿用 `watchlist:write`，截图与 HTML 下载继续要求 `evidence:read`，并检查项目权限及 SHA-256 完整性。截图直接挂在监视项的复查记录下，无需先创建仿冒告警。保存的文件复用对象存储和证据下载机制，监视截图保留期采用 `retention.findings_days`，删除时不会删掉仍被其他证据引用的文件版本。
