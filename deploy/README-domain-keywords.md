# 监视列表中的域名关键词

升级 API、worker 和前端后，打开「监视列表」，默认显示「关键词」标签；原来的域名复查、内容与截图入口在「监视域名」标签，地址为 `/watchlist?tab=domains`。本次功能不新增数据库迁移。

关键词页与「设置 → 关键词规则」使用同一份规则，修改后保存为新版本，并记录操作者和修改说明。可在设置页的版本历史中查看和恢复。

- **品牌词**：用于发现包含品牌或相似拼写的域名。短词按规则中的长度阈值，只做完整词和组合匹配。
- **受限品牌词**：必须与指定词缀组合才算命中，例如 `orbit` 与 `fund`。支持在页面修改词缀。
- **官方域名**：用于识别官方域名被嵌入其他域名等情形。
- **合法第三方**：排除已确认无关的相似域名；已有告警仍需在告警页面处理。

品牌词和词缀支持中文等 Unicode 文字、数字和连字符，长度为 2–63 个字符，不能只有连字符；保存时去除首尾空白并转为小写。配置页已保存的中文词（如 `样本`、`品牌`）可直接查看命中域名和删除，无需重新添加。匹配时忽略连字符：同一有效词不能同时属于品牌词和受限品牌词，同一类别里也不能再加只是连字符写法不同的同一个词（如已有 `orbit` 时添加 `o-rbit`）。域名自动保存为可注册域，如 `careers.example.org` 保存为 `example.org`。中文域名的 Unicode 和 Punycode 写法使用同一匹配器；中文短词也遵守长度阈值，简繁体品牌词需分别配置。

添加前可粘贴样例域名试跑，最多 200 个。试跑不会保存规则或发出扫描任务。各列表和试跑结果支持分页及每页条数选择。

「近 30 天发现」统计当前项目中按该词主要命中原因归属的域名发现；同一个发现的重复原因不重复计数。统计查询超过 10 秒时显示 `—`，关键词列表仍可使用。「查看域名」展示匹配发现、分数、级别、最后发现时间和相关告警链接；可将误报域名设为合法第三方。系统不会直接打开可疑网站。

## 历史回溯

在监视列表新增或修改关键词后，系统按类别安排回溯：品牌词触发 crt.sh 和 dnstwist，受限品牌词触发 crt.sh，官方域名触发 dnstwist；合法第三方不触发。删除不触发回溯，以免占用最小间隔、挡住紧接着新增的词。也可点击「立即回溯」。配置页保存规则不自动触发此回溯。

两个页面另有「立即扫描已保存的关键词」，可以选择单个词主动搜索；域名范围包括 crt.sh、dnstwist、urlscan，配置页也能扫描文本词。逐个数据源显示排队、运行中、间隔不足和不可用状态。详见 [立即扫描说明](README-keyword-scan.md)。

回溯遵守连接器的启用、审批、凭据和节点就绪检查。有运行中的任务时不重复安排；crt.sh 至少间隔 1 小时，dnstwist 至少间隔 12 小时。界面会区分已排队、运行中、间隔不足及当前不可用。回溯不可用或排队失败时，已保存的规则版本仍然保留；应修复连接器或队列配置后再回溯。

**采集节点也需要更新镜像**，才能发送新增的受限品牌词组合查询。旧节点仍只能查询原有品牌词；更新节点后可在允许的间隔后手动回溯。既有发现不会因删除关键词被删除，也不会在本次保存时自动重新评分。

## 权限

查看需要 `watchlist:read`；增删关键词、修改词缀和标记合法第三方需要 `rules:write`；手动回溯需要 `watchlist:write`；试跑需要 `rules:test`。沿用现有角色授权，分析员可操作，只读用户只能查看。
