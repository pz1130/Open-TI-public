# 冒充社交账号检测

升级时先执行 `uv run opti db-upgrade`（迁移 0031），然后重启 API、worker、scheduler 和境外采集节点，并发布前端构建。

## 启用

两个平台适配器默认关闭，须先经法务审查后在「连接器」中批准并启用：

- `social_bluesky`：Bluesky 公开 AppView（默认 `https://public.api.bsky.app`，可在设置中改为自建 AppView）。
- `social_mastodon`：在所配置的实例上用未登录的公开接口搜索（默认只有 `mastodon.social`，最多 10 个）。

在 remote 模式下两者由境外采集节点执行，境内只检查是否启用与批准。

## 使用

在左侧「社交账号保护」添加要保护的账号：Bluesky 填 handle（如 `example.bsky.social`），Mastodon 填 `user@instance`。可加补充搜索词（如中文名称，最多 5 个）和已知合法账号（粉丝号、地区分支等，填 handle 或平台永久 ID）。是否保护高管个人账号由管理员决定。

系统每十分钟调度到期任务，每个账号每天检查一次；适配器未启用、所有搜索都失败或整轮超时（300 秒）时约一小时后重试，超时前已打分的结果照常保存。可点击「立即检查」。每轮：

1. 查受保护账号自身资料，刷新显示名与官方头像哈希（Bluesky 已知 DID 时按 DID 查，账号改名后账号名随之更新）。账号不存在时显示「账号不存在」，本轮不搜索；查资料失败时沿用上次保存的资料。
2. 用显示名、账号名和补充搜索词（最多 7 个）搜索账号，每轮最多处理 200 个不同账号。
3. 排除受保护账号本身、已知合法账号，以及账号所在域名属于本机构官方域名的账号（如 `news.sbr.int`）；搜索结果已标为下架的账号不打分。没有名称相似信号的结果直接丢弃，不保存、不下载头像；每轮最多下载 50 个候选头像，下载失败或超出上限时沿用上次的头像哈希。
4. 按显示名、账号名、头像、简介自称官方、注册不满 30 天打分。仅名称相似最高 35 分（低危，只在候选列表可见）；中危及以上开告警，名称与头像都相似为高危。同一冒充号被多个受保护账号搜到时取最高分；级别升高且高于仍未结的告警时才再次告警。Mastodon 主页链接只认账号所在服务器上的地址。
5. 对有未结告警的候选（每个受保护账号最多 50 个）复查资料，平台确认不存在或停用时标「账号已不存在」，不自动关闭告警。

候选列表中，低危候选可「提升为告警」（打开预填的人工提交表单）；误报可「标为合法账号」。

## 数据边界

- 外发：受保护账号的账号名、显示名与补充搜索词，发往 Bluesky AppView 或所配置的 Mastodon 实例；以及候选头像的下载请求。
- 保存：候选的账号名、显示名、主页链接、注册时间、简介前 500 字、头像 dHash 与 SHA-256、得分与信号。头像只在内存中计算哈希，不保存图片；不采集帖子、关注关系、粉丝数。得分不足 20 的账号不保存。
- 头像只从平台自己的图片主机下载：Bluesky 为 `cdn.bsky.app`，Mastodon 为所配置实例及其子域名；不跟随重定向，最大 1 MB，只接受 PNG/JPEG/WebP。受保护账号在未配置的 Mastodon 实例上时取不到官方头像，本轮不比对头像——把该实例加入搜索实例即可。
- 保留：90 天未再看到且从未关联告警的候选由每日保留任务删除；删除受保护账号会删除其候选，已产生的发现与告警保留供审计。

## 限制

- Mastodon 没有全网搜索，只覆盖所配置实例已知的账号。搜索的实例应同时加入下架平台名单（「配置 → 下架」中 `mastodon` 的 hosts），以免人工提交这些链接时被沙箱访问。
- 名称与头像相似只是人工复核线索，不能证明冒充；告警不由沙箱截图，证据请分析员上传。下架走平台举报模板，SLA 72 小时。
- X、微博等平台尚未接入。

## 接口验证记录

2026-10-14 用真实接口人工验证：未登录的 Bluesky `app.bsky.actor.searchActors` 与 `app.bsky.actor.getProfile` 返回 200，账号不存在时返回 400 `Profile not found`；`mastodon.social` 的 `/api/v2/search?type=accounts` 与 `/api/v1/accounts/lookup` 未登录返回 200，账号不存在时返回 404。Bluesky 冒充举报入口为资料页「举报账号」，上线前请再次核对平台名单中的举报链接。

查看沿用 `watchlist:read`，添加、编辑、删除、立即检查、标为合法沿用 `watchlist:write`。所有写操作记录审计，API 按当前项目隔离数据。
