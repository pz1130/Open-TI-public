# 告警忽略和自动恢复

有告警研判权限的用户可在告警队列或详情点击「忽略」。忽略不删除告警，也不建立域名屏蔽规则，不会停止后续扫描或影响同一域名的其他发现。原状态、证据和历史均保留，并显示「已忽略」标签。

主列表默认排除忽略项；通过「仅已忽略」查看，或选择「包含已忽略」。可随时点击「取消忽略」恢复。只有待处理或处理中的告警能被忽略，只读用户不能操作；忽略与取消忽略均记录审计。

后续观测成功取得关键事实，且与忽略时基线不同，会自动取消忽略并恢复主列表，即使风险级别未升高也会生效。恢复沿用原记录，并更新显示的风险和命中原因；后续风险升级另开告警时，仍沿用既有去重流程。相同关键事实重复开告警会继承忽略状态。

比较使用明确字段，不比较整个 JSON：

| 类别 | 关键字段 |
| --- | --- |
| 通用 | 风险级别、风险类别、举报/检测信号、目标 URL |
| 域名及网站 | A / AAAA / CNAME / MX、域名是否存在、注册商、名称服务器、HTTP 状态、标题、最终跳转地址、页面类型、密码输入框、命中的品牌词 |
| 证书 | 指纹、到期时间、颁发者和证书主体；证书监控还沿用到期风险级别变化 |
| 社交冒充 | 账号名、显示名、简介、头像指纹、账号失效信息 |
| 公开文本、泄漏和漏洞 | 标题、链接、泄漏数据种类/规模、验证标记、漏洞产品和勒索相关标记 |
| 代码泄漏 | 文件位置、代码版本、命中词、已脱敏的密钥指纹和规则 |

扫描/抓取/截图时间、来源顺序、数组顺序、空白格式、整页 HTML 哈希、截图哈希、累计转载次数不参与比较。URL 忽略片段及常见追踪和会话参数。查询失败、缺失的富化结果或 HTTP 5xx 不作为这些字段的变化。原始密钥不写入比较基线。

忽略项不参与待处理/逾期列表和数量，不继续自动截图，也暂停尚未发送的即时通知、日报待办、SIEM 推送和自动工单。已发送的通知和工单保留；自动恢复后重新进入正常处理流程，已成功投递的渠道不会重复投递。报告中的历史统计继续保留这些告警。

部署需要执行 `uv run opti db-upgrade`，更新 API、worker、scheduler 以及前端。
